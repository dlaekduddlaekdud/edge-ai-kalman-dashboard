# 논문 요약 — Edge AI 기반 적응형 칼만 필터의 임베디드 실시간 적용 연구

한국외국어대학교 정보통신공학과 졸업논문 
임다영, 신유빈 · 지도교수 손경락

이 문서는 대시보드가 시각화하는 실험 데이터의 출처와 확정 수치를 정리한 문서입니다.

---

## 연구 개요

자원이 제한된 MCU 계층에서 센서 노이즈를 보정하는 경량 상태 추정 기법을 다룹니다. 저속 주차 보조 시스템의 정밀 거리 추정을 응용 대상으로, STM32F446RE 위에서 세 가지 칼만 필터를 **병렬 실행**해 정확도와 실시간성을 비교했습니다.

표준 칼만 필터는 측정 노이즈 공분산 R을 고정값으로 두기 때문에 표면 반사율 등에 따라 변하는 센서 노이즈 특성을 반영하지 못합니다. 이를 R 적응으로 해결하되, 기존 규칙 기반 방식이 잔차 통계라는 단일 정보에만 의존하는 한계를 다변량 feature 기반 TinyML 추론으로 보완하는 것이 핵심 접근입니다. 프로세스 노이즈 Q는 저속 등속 직선 운동이라는 대상 특성상 시변 요소가 아니므로 고정했습니다.

## 연구 질문

| | 질문 |
|---|---|
| RQ1 | TinyML 기반 R 추정이 200 Hz 제어 루프의 시간 제약 내에서 실시간 동작 가능한가 |
| RQ2 | TinyML-AKF는 CM-AKF 대비 복합 노이즈 환경(E2·E3·E5)에서 위치 추정 정확도와 R 추정 거동에 어떤 차이를 보이는가 |
| RQ3 | 잔차 통계 외 feature(sensor disagreement, signal rate)가 R 추정에 실제로 기여하는가 |

## 비교 대상 알고리즘

세 알고리즘은 동일한 1D 스칼라 상태 공간 모델을 공유하며, **R의 처리 방식만 다릅니다.** 이 설계로 적응 메커니즘 자체의 효과를 분리해 평가할 수 있습니다.

| 알고리즘 | R 처리 |
|---|---|
| Raw | 필터 미적용, VL53L0X 직접 측정값 (기준선) |
| Fixed KF | R = R₀ 고정 |
| CM-AKF | Covariance Matching으로 매 스텝 갱신, 클램프 [1.0, 10000.0] mm² |
| TinyML-AKF | 학습된 신경망 추론으로 매 스텝 갱신, 동일 클램프 |

## 하드웨어 구성

| 구분 | 부품 | 사양 |
|---|---|---|
| MCU | STM32F446RE NUCLEO | Cortex-M4, 180 MHz, FPU, Flash 512 KB, SRAM 128 KB |
| ToF (주 측정) | VL53L0X | I²C, Continuous 모드 ~50 Hz, FOV 25° |
| 엔코더 (예측 입력) | FIT0450 ×2 | 8 PPR × 120:1 = 960 pulse/rev, 200 Hz |
| 초음파 (보조 feature) | HC-SR04 | TIM3 Input Capture, ~20 Hz |
| 모터 드라이버 | TB6612FNG | MOSFET H-bridge |
| 무선 로깅 | HC-06 | 115200 baud, DMA 더블 버퍼링, 50 Hz |

VL53L0X는 KF Update의 측정 채널, 엔코더는 Prediction의 운동학적 입력, HC-SR04는 TinyML의 F4(sensor disagreement) 입력으로만 사용됩니다. HC-SR04는 KF Update에 직접 관여하지 않습니다.

## TinyML 모델

| 항목 | 값 |
|---|---|
| 구조 | MLP 6 → 16 → 8 → 1 |
| 파라미터 | 257개 |
| 양자화 | Post-training INT8, 파일 크기 3.20 KB |
| Flash 점유 | 512 KB 대비 약 0.06% |
| 출력 변환 | log1p 공간 학습 → 추론 시 expm1 복원 후 클램프 |
| 학습 라벨 | Covariance Matching 기반 pseudo-label (W=20) |
| 배포 | ST Edge AI Core 4.0 (stedgeai CLI) |

R이 heavy-tailed 분포를 가지므로 원 공간에서 학습하면 큰 R 샘플이 손실 함수를 지배하고 INT8 출력 텐서의 동적 범위 표현도 어려워집니다. log1p 변환으로 라벨 범위를 [0.69, 9.21]로 압축해 두 문제를 동시에 해결했습니다.

### 입력 feature

| ID | 이름 | 의미 |
|---|---|---|
| F1 | Residual | 예측값과 측정값의 순간 불일치 |
| F2 | Residual Variance | 최근 100 ms 측정 노이즈 강도 |
| F3 | Residual Mean | 측정 바이어스 누적 경향 |
| F4 | Sensor Disagreement | 주센서·보조센서 간 일치도 |
| F5 | Measurement Rate | 윈도우 내 정상 측정 비율 |
| F6 | Signal Rate | 표면 반사율 직접 지표, 잔차 변화의 선행 지표 |

## 실험 시나리오

| ID | 목적 | 조건 | 반복 |
|---|---|---|---|
| E0 | KF 정상 수렴 검증 | Python 합성 데이터, 2,000 스텝 | 1회 |
| E1 | 정상 접근 baseline | 흰 우드락 벽, 500 mm 수동 굴림 | 1차 5 + 2차 5 run |
| E2 | 벽 반사율 변화 | 흰/검정 우드락, 투명 아크릴 | 1차 9 + 2차 9 run |
| E3 | 동적 ToF 차단 | 알루미늄 판 0.75~1초 동적 진입 | 1차 5 + 2차 5 run |
| E4 | 정적 장기 안정성 | 정지 상태 30분 연속 | 3 run |
| E5 | 미지 표면 일반화 | 회색 단면 우드락 (학습 미포함) | 5 run |

1차 측정은 25컬럼 펌웨어(Fixed + CM)로 수집해 TinyML 학습에 사용하고, 2차 측정은 28컬럼 펌웨어로 재수집해 3-way 라이브 비교에 사용했습니다. 학습·평가 데이터의 펌웨어 버전과 측정 시점을 분리해 data leakage를 방지한 설계입니다. 데이터 분할은 run 단위로 수행했습니다 (동일 run 내부 random split 금지).

## RQ별 결론

**RQ1 — 실시간 동작 가능.** 추론 시간이 TinyML 목표 예산 500 µs의 7.1%(약 14배 안전 마진), 200 Hz 제어 루프 예산 5 ms 기준 0.71% 수준에서 동작했습니다. 242,992회 누적 측정의 표준편차 0.007 µs는 INT8 정수 연산의 입력 무관 결정론적 특성을 보여줍니다.

**RQ2 — R 추정 거동에서 차이, 위치 RMSE는 동등.** E3 차단 이탈 후 R이 1,000 mm² 이하로 회복되는 시점이 TinyML-AKF 60 ms(3 frame) 대 CM-AKF 160 ms(8 frame)로 약 2.7배 빨랐습니다. 다만 외란 구간이 평균 약 1초로 짧아 이 차이가 위치 RMSE로 누적되지는 않았습니다. 두 적응형 알고리즘 모두 E3에서 Fixed KF 대비 약 1/3 수준의 RMSE를 달성했습니다.

**RQ3 — 기여 확인.** F6 signal_rate가 차단 진입보다 4 frame(80 ms) 먼저 baseline ±3σ를 벗어나 선행 지표로 작동했습니다. 또한 표면별 signal_rate가 가시광 반사율과 단조 관계에 있지 않았습니다 — 가시광상 거의 투명한 아크릴(13.2 Mcps)이 가시광 흡수재인 검정 우드락(11.1 Mcps)보다 높게 측정되었습니다. 사람이 직관적 규칙으로 노이즈 환경을 예측할 수 없는 영역이라는 뜻이고, 다변량 학습 기반 접근의 근거가 됩니다.

## Ablation

6-feature 메인 모델과 잔차 통계만 사용한 3-feature 축소 모델(209 파라미터)을 hold-out 데이터에서 비교했습니다.

| 모델 | Test MAE_R (f32) | Test MAPE_R | Test MAE_R (INT8) |
|---|---:|---:|---:|
| 6-feature | 357.31 mm² | 34.3% | 273.13 mm² |
| 3-feature | 387.72 mm² | 20.1% | 393.94 mm² |

정상 표면에서는 잔차 통계 3개만으로도 CM-AKF에 근접합니다. 정상 주행 시 잔차 평균이 0에 가까워 `F2 ≈ R + P` 관계가 성립하기 때문입니다. 반면 동적 outlier(E3)와 광학적 특이 표면(E2 투명 아크릴)에서는 이 근사가 깨지고, 3-feature 모델이 명확한 열위를 보였습니다.

F5는 전체 24 run에서 `range_status ≠ 0`이 발생하지 않아 상수 입력으로 작동했습니다. 따라서 이 ablation은 실질적으로 F4·F6 추가의 가치를 측정한 것입니다.

## 한계

- **학습 환경 다양성**: 단일 거리(500 mm), 단일 조명, 단일 작업자, 학습 표면 3종에 한정됩니다.
- **F5 변별력 미검증**: 24 run 전체에서 신호 손실이 발생하지 않아 F5의 기여를 정량 검증할 수 없었습니다. 극단적 신호 손실 환경 대비 예비 채널로 유지했습니다.
- **동적 차단 재현성**: 수동 진입 방식이라 차단 구간 길이 691~1455 ms, 진입 위치 encoder 213~273 mm로 변동했습니다.
- **IR 반사 가정**: 가시광 반사율로 940 nm IR 특성을 추정한 초기 시나리오 설계가 실측에서 두 차례 어긋나 재설계했습니다. 검정 우드락은 가시광 흡수재이지만 IR 영역에서는 약 50% 반사율을 가집니다.
- **무선 무결성**: E4 30분 측정에서 HC-06 무선 구간 프레임 도달율 약 93%. 펌웨어 측 DMA TX는 0 drop이었고, `seq` 필드로 시간축 재구성이 가능해 분석 정합성은 유지됩니다.
- **Ground Truth 산정**: 수동 굴림의 바퀴 슬립으로 엔코더 누적 이동량이 실제 거리의 75~94%만 반영했습니다. ToF 양 끝점을 거리 anchor로 두고 엔코더를 구간 보간 변수로만 사용하는 방식을 채택했습니다.

## Ground Truth 산정 방식

논문 4.1.2절 기준이며, `lib/e1-metrics.ts`의 `getGroundTruth()`가 이 정의를 구현합니다. CSV에 유효한 `gt_distance_mm` 값이 있으면 그대로 사용하고, 전 구간 0인 경우에만 아래 공식으로 복원합니다.

```
GT(k) = ToF_start − (enc(k) / enc_last) · (ToF_start − ToF_end)
```

- `ToF_start`, `ToF_end`: 측정 시작·종료 시점 VL53L0X 값 (각 첫·끝 5 frame 평균)
- 엔코더는 절대 거리 기준이 아니라 두 anchor 사이의 진행 비율을 분배하는 보간 변수로만 사용
- 엔코더 단독 누적을 절대 GT로 쓰면 바퀴 슬립만큼 RMSE가 과대평가됨
- E4는 정지 시나리오이므로 전 구간 VL53L0X 평균을 GT로 사용
