# 논문 최종본 기반 업그레이드 계획 (P0~P7)

> **작성 시점 주의**: 이 문서는 2026-05-23에 로컬로 작성해 작업 기준으로 사용한 계획서를 커밋 로그(`p0:` ~ `p3~p7:`) 기준으로 사후 재구성한 것이다.
> 원본은 저장소에 커밋하지 않아 남아 있지 않으며, 아래 항목은 실제 커밋 내역에서 역으로 정리했다. 계획 시점의 문장 그대로가 아니라 실행 결과 기준 기록이다.

## 배경

졸업논문 최종본이 확정되면서 두 가지가 바뀌었다.

1. 실험 CSV 스키마가 18컬럼에서 25/28컬럼 이원 구조로 변경됨
2. 논문에 확정 수치가 들어가면서, 대시보드 표시값이 논문과 일치해야 하는 제약이 생김

기존 구현은 18컬럼 단일 스키마를 가정하고 대시보드 자체 계산값을 표시하고 있었다. 
우선순위를 P0~P7로 나눠 순차 반영했다.

## 이후 변경 (계획 외)

계획 수립 시점 이후에 판단이 바뀐 항목이다.

- **realtime 게이지 (P2)** — 별도 라우트로 두었으나 `/results`로 통합하고 `/realtime`은 308 리다이렉트로 정리했다. 
- 독립 페이지로 유지할 만한 내용량이 아니었고, README Limitations에서 실시간 스트리밍을 범위 밖으로 명시한 것과 라우트 존재가 상충했다.
- **Ablation CSV 동적 로드 (P3~P7)** — 파싱·열화 판정·가중평균이 페이지 컴포넌트 안에 있어 단위 테스트가 불가능했다. 
- `lib/ablation-holdout.ts`로 분리하고 판정 임계를 명명 상수로 승격했다.
